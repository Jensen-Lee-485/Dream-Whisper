# Dreamer Analyst - 技术文档

> AI 梦境分析助手：记录梦境 → AI 解析 → 生成图像 → 生成视频

---

## 项目概述

**Dreamer Analyst** 是一款基于 AI 的梦境记录与分析应用。用户描述梦境后，系统会：
1. 使用 LLM 解析梦境符号与心理含义
2. 生成梦境可视化图像
3. 🆕 生成梦境短视频（5-10秒）

---

## 三大核心功能

### 核心功能一：AI 梦境解析

**目标**：将用户的梦境描述转化为符号分析 + 心理洞察

```
用户输入 → GPT-4o 解析 → 返回结构化分析报告
```

#### 实现代码

```typescript
// app/api/analyze/route.ts
import OpenAI from 'openai';
import { NextResponse } from 'next/server';

const openai = new OpenAI({ apiKey: process.env.OPENAI_API_KEY });

const SYSTEM_PROMPT = `你是一位专业的梦境分析师，融合荣格分析心理学和弗洛伊德理论。

分析梦境时请：
1. 识别核心符号（人物、场景、物品、情绪）
2. 解释每个符号的象征含义
3. 分析整体情绪基调
4. 给出与现实生活的可能关联
5. 提供建设性的心理建议

返回 JSON 格式：
{
  "symbols": [{"symbol": "符号", "meaning": "含义"}],
  "emotional_tone": "情绪基调",
  "psychological_insight": "心理洞察",
  "life_connection": "现实关联",
  "suggestions": ["建议1", "建议2"],
  "image_prompt": "用于生成梦境图像的英文描述，超现实风格，包含关键视觉元素"
}`;

export async function POST(req: Request) {
  const { dream } = await req.json();

  const response = await openai.chat.completions.create({
    model: 'gpt-4o',
    messages: [
      { role: 'system', content: SYSTEM_PROMPT },
      { role: 'user', content: `请分析这个梦境：${dream}` }
    ],
    response_format: { type: 'json_object' },
    temperature: 0.7
  });

  const analysis = JSON.parse(response.choices[0].message.content!);
  return NextResponse.json(analysis);
}
```

**关键点**：
- 使用 `response_format: { type: 'json_object' }` 确保返回结构化数据
- 系统提示词中要求返回 `image_prompt`，用于后续图像/视频生成

### 核心功能二：梦境图像生成

**目标**：将梦境描述转化为超现实风格的可视化图像

```
分析结果中的 image_prompt → DALL-E 3 → 返回 1024x1024 图像
```

#### 实现代码

```typescript
// app/api/generate-image/route.ts
import OpenAI from 'openai';
import { NextResponse } from 'next/server';

const openai = new OpenAI({ apiKey: process.env.OPENAI_API_KEY });

export async function POST(req: Request) {
  const { prompt } = await req.json();

  // 增强提示词，确保梦境风格
  const enhancedPrompt = `${prompt}, 
    surrealist dreamscape style, 
    ethereal lighting, 
    soft dreamlike atmosphere, 
    Salvador Dali inspired, 
    no text or watermarks`;

  const response = await openai.images.generate({
    model: 'dall-e-3',
    prompt: enhancedPrompt,
    size: '1024x1024',
    quality: 'standard',
    n: 1
  });

  return NextResponse.json({ 
    imageUrl: response.data[0].url 
  });
}
```

**关键点**：
- 添加风格增强后缀确保统一的梦境美学
- DALL-E 3 会自动优化提示词，无需过度细化

### 核心功能三：梦境视频生成 🆕

**目标**：将梦境转化为 5-10 秒的动态短视频

```
image_prompt → Runway Gen-3 API → 返回 MP4 视频
```

#### 方案 A：Runway Text-to-Video（推荐）

```typescript
// app/api/generate-video/route.ts
import { NextResponse } from 'next/server';

export async function POST(req: Request) {
  const { prompt } = await req.json();

  // Runway API 调用
  const response = await fetch('https://api.runwayml.com/v1/text_to_video', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${process.env.RUNWAY_API_KEY}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      prompt: `${prompt}, dreamlike motion, slow ethereal movement, cinematic`,
      model: 'gen3a_turbo',
      duration: 5,  // 5秒
      ratio: '16:9'
    })
  });

  const data = await response.json();
  
  // Runway 返回任务 ID，需要轮询获取结果
  return NextResponse.json({ 
    taskId: data.id,
    status: 'processing'
  });
}

// 轮询获取视频结果
export async function GET(req: Request) {
  const { searchParams } = new URL(req.url);
  const taskId = searchParams.get('taskId');

  const response = await fetch(`https://api.runwayml.com/v1/tasks/${taskId}`, {
    headers: {
      'Authorization': `Bearer ${process.env.RUNWAY_API_KEY}`
    }
  });

  const data = await response.json();
  
  if (data.status === 'SUCCEEDED') {
    return NextResponse.json({ 
      status: 'completed',
      videoUrl: data.output[0]
    });
  }
  
  return NextResponse.json({ 
    status: data.status,
    progress: data.progress 
  });
}
```

#### 方案 B：Replicate Image-to-Video（备选）

```typescript
// 先生成图像，再转视频
import Replicate from 'replicate';

const replicate = new Replicate({ auth: process.env.REPLICATE_API_TOKEN });

export async function POST(req: Request) {
  const { imageUrl } = await req.json();

  // 使用 Stable Video Diffusion
  const output = await replicate.run(
    "stability-ai/stable-video-diffusion:3f0457e4619daac51203dedb472816fd4af51f3149fa7a9e0b5ffcf1b8172438",
    {
      input: {
        input_image: imageUrl,
        motion_bucket_id: 127,  // 控制运动幅度
        fps: 7,
        cond_aug: 0.02
      }
    }
  );

  return NextResponse.json({ videoUrl: output });
}
```

**关键点**：
- Runway 是异步任务，需要轮询获取结果
- 备选方案使用图像转视频，成本更低
- 视频生成耗时约 30-60 秒，前端需显示进度

## 前端核心组件

### 主页面布局

```tsx
// app/page.tsx
'use client';
import { useState } from 'react';
import DreamInput from '@/components/DreamInput';
import AnalysisResult from '@/components/AnalysisResult';
import DreamMedia from '@/components/DreamMedia';

export default function Home() {
  const [dream, setDream] = useState('');
  const [analysis, setAnalysis] = useState(null);
  const [imageUrl, setImageUrl] = useState('');
  const [videoUrl, setVideoUrl] = useState('');
  const [loading, setLoading] = useState({ analyze: false, image: false, video: false });

  const handleAnalyze = async () => {
    setLoading(prev => ({ ...prev, analyze: true }));
    const res = await fetch('/api/analyze', {
      method: 'POST',
      body: JSON.stringify({ dream })
    });
    const data = await res.json();
    setAnalysis(data);
    setLoading(prev => ({ ...prev, analyze: false }));
  };

  const handleGenerateImage = async () => {
    if (!analysis?.image_prompt) return;
    setLoading(prev => ({ ...prev, image: true }));
    const res = await fetch('/api/generate-image', {
      method: 'POST',
      body: JSON.stringify({ prompt: analysis.image_prompt })
    });
    const data = await res.json();
    setImageUrl(data.imageUrl);
    setLoading(prev => ({ ...prev, image: false }));
  };

  const handleGenerateVideo = async () => {
    if (!analysis?.image_prompt) return;
    setLoading(prev => ({ ...prev, video: true }));
    // 启动视频生成任务
    const res = await fetch('/api/generate-video', {
      method: 'POST',
      body: JSON.stringify({ prompt: analysis.image_prompt })
    });
    const { taskId } = await res.json();
    
    // 轮询获取结果
    const pollResult = async () => {
      const statusRes = await fetch(`/api/generate-video?taskId=${taskId}`);
      const status = await statusRes.json();
      if (status.status === 'completed') {
        setVideoUrl(status.videoUrl);
        setLoading(prev => ({ ...prev, video: false }));
      } else if (status.status !== 'FAILED') {
        setTimeout(pollResult, 3000);  // 每3秒轮询
      }
    };
    pollResult();
  };

  return (
    <main className="min-h-screen bg-gradient-to-b from-indigo-950 to-purple-900 p-8">
      <div className="max-w-4xl mx-auto">
        <h1 className="text-4xl font-bold text-white text-center mb-8">
          🌙 Dreamer Analyst
        </h1>
        
        <DreamInput 
          value={dream} 
          onChange={setDream} 
          onSubmit={handleAnalyze}
          loading={loading.analyze}
        />
        
        {analysis && (
          <>
            <AnalysisResult analysis={analysis} />
            <DreamMedia
              imageUrl={imageUrl}
              videoUrl={videoUrl}
              onGenerateImage={handleGenerateImage}
              onGenerateVideo={handleGenerateVideo}
              loading={loading}
            />
          </>
        )}
      </div>
    </main>
  );
}
```

### 梦境输入组件

```tsx
// components/DreamInput.tsx
interface Props {
  value: string;
  onChange: (v: string) => void;
  onSubmit: () => void;
  loading: boolean;
}

export default function DreamInput({ value, onChange, onSubmit, loading }: Props) {
  return (
    <div className="bg-white/10 backdrop-blur-lg rounded-2xl p-6 mb-8">
      <label className="text-white/80 text-sm mb-2 block">
        描述你的梦境...
      </label>
      <textarea
        value={value}
        onChange={(e) => onChange(e.target.value)}
        placeholder="我梦见自己在云层之上飞翔，周围是金色的阳光，远处有一座悬浮的城堡..."
        className="w-full h-40 bg-white/5 rounded-xl p-4 text-white 
                   placeholder:text-white/30 border border-white/10 
                   focus:border-purple-400 focus:outline-none resize-none"
      />
      <button
        onClick={onSubmit}
        disabled={loading || !value.trim()}
        className="mt-4 w-full py-3 bg-gradient-to-r from-purple-500 to-pink-500 
                   rounded-xl text-white font-semibold hover:opacity-90 
                   disabled:opacity-50 disabled:cursor-not-allowed
                   transition-all duration-300"
      >
        {loading ? '正在解析...' : '✨ 解析梦境'}
      </button>
    </div>
  );
}
```
